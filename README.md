# ドパガキ五目 ～待てない五目並べ～

相手の番に連打して、暴発させたり割り込んだりする五目並べです。
YouTube「AIでつくってためそ」第7回で、**ChatGPT（Codex）×Claude 共同制作**で作りました。

▶ **遊ぶ：https://ai-tsukuttetameso.github.io/tsukutte-tameso-dopagaki-gomoku/**

## 遊び方
- 15×15の盤で、縦・横・斜めに **5つ以上並べたら勝ち**（禁じ手なし）
- 交互に打つ。でも **相手の番の間は「連打！」ボタンを連打できる**（PCは黒＝Aキー、白＝Lキー）
- 連打 **10回で暴発**：相手の次の石が、つながりにくい場所へランダムに置かれる
- 連打 **20回で割り込み**：相手の番なのに、好きな場所に自分の石を1個置ける（その後3秒休み）
- 4つ並ぶと「リーチ！」。対局後に「ドパガキ度○％」と称号を診断
- モード：CPU対戦（🔰はじめて（解説つき）／のんびり／ふつう／脊髄反射）・2人対戦（1台で）
- パソコン（クリック・キーボード）とスマホ（タップ。選んでから「ここに置く」で確定）に対応

## 作り方
- 役割：ChatGPT（Codex）が仕様書とテスト・レビュー、Claudeが実装・テスト・修正
- `index.html` 1ファイルだけ（HTML・CSS・JavaScript）。画像ファイル・外部ライブラリなし
- 外部への通信は一切しません。設定（モード・音など）だけをブラウザのlocalStorageに保存します
